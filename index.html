Sobre mí

Perfil, enfoque y forma de trabajo

Soy desarrollador de software con experiencia principalmente en el ecosistema .NET, trabajando en el desarrollo de APIs, integraciones y soluciones backend. Tengo conocimientos en arquitectura limpia, Entity Framework, MediatR y Result-Oriented Programming, además de experiencia en testing unitario y diseño de soluciones mantenibles.
Trabajo con bases de datos relacionales como SQL Server, PostgreSQL y Oracle, así como con bases de datos NoSQL como MongoDB. También cuento con conocimientos de tecnologías frontend como JavaScript, TypeScript, React, HTML y CSS.
Utilizo herramientas como Git, Azure DevOps, Docker y Postman en mis procesos de desarrollo. Además, incorporo herramientas de inteligencia artificial como OpenCode para asistir y optimizar distintas etapas del trabajo.
Me interesa seguir aprendiendo, mejorar continuamente mis prácticas de desarrollo y construir soluciones de software sólidas, mantenibles y que aporten valor real.

Proyectos

Sistemas, migraciones y paquetes construidos con .NET

Proyecto destacado

Sistema de Gestión de Ventas

Aplicación en .NET 8 con arquitectura limpia, MediatR y patrón Result-Oriented Programming (ROP). Implementa autenticación, validaciones con FluentValidation y exportación PDF de reportes, además de una licencia que se activa después de un período de prueba.

  • .NET 8
  • EF Core
  • PostgreSQL
  • MediatR
  • ROP

Migrador Oracle → PostgreSQL

Herramienta para migrar datos masivos desde Oracle hacia PostgreSQL utilizando EF Core y EntityFramework.Extensions. Incluye procesamiento por lotes, logs de auditoría y validación de consistencia.

  • .NET 8
  • EF Core
  • Oracle
  • PostgreSQL
  • EF Extensions

Integración de Mensajería con RabbitMQ

Proyecto de arquitectura distribuida donde se implementan colas de mensajería para la comunicación entre microservicios, con manejo de confirmaciones (ACK) y reintentos automáticos.

  • .NET 8
  • RabbitMQ
  • MediatR
  • CQRS
  • Docker

Creación de paquetes NuGet (Azure Artifacts)

Mapeador de objetos y constructor de filtros dinámicos, publicados como paquetes NuGet en Azure Artifacts.

  • .NET 8
  • EntityFramework
  • PostgreSQL

Mapeador de objetos

Mapeador de objetos ligero y de alto rendimiento para .NET. Alternativa perfecta a AutoMapper para escenarios de asignación simples a moderados con una sobrecarga mínima.

Constructor de filtros dinámicos

Clase genérica en C# para construir filtros dinámicos utilizando expresiones lambda (Expression<Func<T, bool>>). Ideal para aplicaciones con Entity Framework Core, LINQ to Objects o cualquier fuente de datos que soporte expresiones.
